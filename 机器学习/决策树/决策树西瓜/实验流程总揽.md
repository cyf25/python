# 决策树西瓜分类实验流程总揽

## 1. 实验目标
使用C4.5决策树算法对西瓜数据集进行分类，实现以下目标：
- 构建基于信息增益率的决策树模型
- 可视化决策树结构
- 评估模型性能
- 详细记录计算过程

## 2. 实验数据
- 数据文件：watermalon.txt
- 特征：色泽、根蒂、敲击、纹理、脐部、触感
- 标签：好瓜(是)/坏瓜(否)
- 数据分割：70%训练集，30%测试集

### 3.2 决策树构建
1. **信息熵计算** (`calcShannonEnt`)
   - 计算数据集的信息熵
   - 记录标签分布和计算结果

2. **条件熵计算** (`calcFeatureCondEntropy`)
   - 计算每个特征的条件熵
   - 记录子数据集划分和熵值计算过程

3. **分裂信息熵计算** (`calcSplitInfo`)
   - 计算特征的分裂信息熵
   - 用于C4.5算法的信息增益率计算

4. **最优特征选择** (`chooseBestFeatureToSplit`)
   - 基于信息增益率选择最优划分特征
   - 记录各特征的条件熵、分裂信息熵和信息增益率

5. **递归构建决策树** (`createTree`)
   - 终止条件：
     - 所有样本标签相同
     - 特征用完或所有特征取值一致
   - 记录每个节点的计算过程和分支决策

### 3.4 模型评估
1. **测试集预测** (`classify`)

2. **性能评估**

     - 数据集分割比例

     - 模型性能总结

## 4. 输出文件
- `决策树计算过程/`目录：包含各节点的详细计算过程
- `决策树可视化图.png`：决策树结构图
- 控制台输出：包含完整的计算过程和评估结果

## 5. 关键算法
- **C4.5算法**：基于信息增益率选择特征
  ```
  信息增益率 = 信息增益 / 分裂信息熵
  ```
- **递归分割**：直到满足终止条件
- **多数表决**：特征用完时采用多数标签
